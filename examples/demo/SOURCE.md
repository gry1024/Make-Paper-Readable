## Recording

`docs/demo.gif` is a screen recording of real browser interactions: language layout switching, text selection, annotation creation, review marking, reading preferences, and scrolling. It does not contain generated UI frames or simulated AI responses. The visible pointer follows actual mouse events. The reproducible Playwright script is `scripts/record-demo.cjs`; run it against a fresh isolated workspace at `http://127.0.0.1:8767`, then encode its WebM recording as GIF.
